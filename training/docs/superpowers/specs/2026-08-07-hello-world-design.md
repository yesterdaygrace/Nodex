# Hello World Go Program — Design

## Scope

Create a standalone Go source file at the training folder root.

## Design

`hello.go` will declare `package main`, import `fmt`, and print exactly
`Hello, World!` from `main` using `fmt.Println`.

## Usage and verification

Run `go run hello.go` from `/home/vinkanika/Documents/CODING/training`.
Success is standard output containing `Hello, World!` followed by a newline.

## Non-goals

No Go module, dependencies, arguments, input, or additional files are required.
