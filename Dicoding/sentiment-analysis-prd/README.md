# Indonesian Sentiment Analysis

Machine-learning/NLP project designed for the Dicoding Sentiment Analysis submission.

## Main Target

- Python
- Independent scraping
- 10,000+ clean samples
- Negative / Neutral / Positive classes
- 3 training experiments
- Deep learning
- Testing accuracy ≥85% minimum
- >92% training and testing accuracy target
- Notebook inference
- Reproducible submission package

## Recommended Data Source

Google Play Store reviews.

## Recommended Experiments

1. TF-IDF + Linear SVM
2. Embedding + BiLSTM
3. Embedding + CNN + BiLSTM

## Required Submission Files

```text
training.ipynb
scrape.py
requirements.txt
sentiment_dataset.csv
```

Package the files into one ZIP.

The notebook must be executed before submission so outputs are visible to the reviewer.

## Labeling

```text
1–2 stars → Negative
3 stars   → Neutral
4–5 stars → Positive
```

## Important

The dataset must be independently collected. Do not submit an existing open-source/Kaggle sentiment dataset as if it were scraped independently.

See `PRD.md` for the complete project specification.
